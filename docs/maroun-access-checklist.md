# المطلوب من مارون قبل ربط القياس والموقع

تُمنح الصلاحيات بدعوات للحسابات المسماة. لا نحتاج كلمة مرور حساب Google، ولا أكواد MFA، ولا مفاتيح دفع الإنتاج. نحدد أولًا بريد Google للشخص الذي سينفذ الربط وبريد المسؤول البديل؛ تبقى ملكية الحسابات باسم الفندق.

| الخدمة | الحساب/البيانات المطلوبة | الصلاحية المطلوبة ولماذا |
|---|---|---|
| Search Console | رابط Property الحالية إن وجدت، الدومين النهائي وكل نطاقات www/بدون www واللغات، اسم المالك المتحقق وطريقة التحقق، أي Properties قديمة، sitemap الفعلي | Full user لمراجعة التقارير وإرسال sitemap. يبقى مارون Verified Owner لإدارة الوصول والتحقق. عند إنشاء Domain property يحتاج المسؤول عن DNS إضافة TXT المعتمد؛ يمكنه تنفيذ الإضافة بدل منحنا حسابه. [مرجع الصلاحيات](https://support.google.com/webmasters/answer/7687615?hl=en) |
| GA4 | Account ID، Property ID الرقمي، Web Stream ID، Measurement ID الحقيقي، اسم المالك، timezone والعملة المعتمدتان، الفلاتر وEnhanced Measurement والأحداث/key events الحالية، قائمة الدومينات ومحرك الحجز | Viewer للقراءة والتدقيق أولًا؛ Editor على الـProperty لتعديل stream/events/configuration. Administrator عند الحاجة إلى إنشاء الحساب/Property أو إدارة المستخدمين، ويحتفظ بها مارون. [مرجع الأدوار](https://support.google.com/analytics/answer/9305587?hl=en) |
| GTM | Account ID وContainer ID الحقيقي ونوعه Web، اسم المسؤول، export للنسخة المنشورة وآخر workspace والتغييرات غير المنشورة، قائمة Tags/Triggers/Variables وCMP الحالية | Account User + Container Edit للتجهيز؛ Approve لإنشاء نسخة قابلة للمراجعة. Publish لمن سينشر لاحقًا فقط عند اعتماد النشر، ويحتفظ به مارون إن كان سيقوم به. يلزم شخصان مسؤولان عن الحساب لضمان الاستمرارية. [مرجع الأدوار](https://support.google.com/tagmanager/answer/6107011?hl=en) |
| الدومين وDNS | اسم المسجل ومزود DNS، أسماء النطاقات/النطاقات الفرعية، authoritative nameservers، export للسجلات الحالية، DNS/CDN/proxy، مسؤول التجديد وتاريخ الانتهاء، طريقة اعتماد تغيير TXT | دور يسمح بتعديل DNS للـzone المحددة عند الحاجة، أو يتولى مارون إضافة TXT والتحقق. لا حاجة لنقل ملكية الدومين أو تغيير A/MX أثناء هذه المهمة |
| الاستضافة | اسم المزود ولوحة التحكم، مسؤول الاستضافة، رابط staging، الدومين/مسار document root الحقيقي، إصدار PHP وامتداداته، نوع DB وإصدارها، ربط المستودع والبرانش، طريقة النشر والنسخ الاحتياطي والاسترجاع، queue/cron/session/cache/CDN، إعدادات TLS/CSP والـrewrite | وصول إلى staging فقط: دور لوحة محدود أو SSH/SFTP بحساب مخصص ومفتاح يُسلّم عبر قناة آمنة، وقراءة السجلات وكتابة ملفات staging. لا صلاحية قاعدة بيانات الإنتاج أو نشر تلقائي. يلزم اعتماد منفصل لاحقًا لأي عمل إنتاج |
| CMS الحالية | حساب admin في staging، theme/plugin versions، export للقيم غير السرية لإعدادات website tracking وcookie consent وcustom HTML/JS، نسخة robots المعتمدة، sitemap والمحتوى والترجمات | حساب staging بدور الإعدادات/المحتوى المطلوبة. تدقيق الأكواد المضافة من CDN والقالب والإضافات أيضًا لتجنب تكرار GA/GTM |
| محرك الحجز/الدفع | اسم المزود، هل الحجز داخلي أم خارجي، الدومين، sandbox URL وحسابات اختبار، آلية تأكيد الحجز والwebhook، مواصفات المبلغ والعملة وrefund/cancel، تأكيد الدعم للcross-domain | وصول sandbox فقط ومفاتيح اختبار إلى مخزن أسرار staging، وصلاحية webhook test. لا مفاتيح live أو مدفوعات حقيقية |

## قرارات وبيانات عمل لازمة

- تعريف «إتمام حجز حقيقي»: دفع مؤكد، أم حجز مؤكد للدفع في الفندق؟ من يعتمد الحجز، ومتى نحتسب الإيراد، وكيف نعالج الإلغاء والاسترداد؟
- اعتماد العملة، timezone، القيمة التي تُرسل بعد الخصم/الضريبة، معرّف حجز غير شخصي، ومصدر السعر الموثوق.
- سياسة الموافقة والخصوصية، البلدان المستهدفة، مدة الاحتفاظ بالاختيار والبيانات، رابط سياسة الخصوصية، ومسؤول الموافقة على الإعلانات إن أضيفت مستقبلًا.
- GA4/GTM منفصلان للاختبار أو خطة واضحة لمنع بيانات staging من تقارير الإنتاج. قائمة زيارات الموظفين وفلاترها دون بيانات ضيوف.
- تأكيد بيانات الفندق والمحتوى والترجمات والصور والدومين canonical؛ لا ننشر بيانات افتراضية أو IDs تجريبية.
- مسؤول اعتماد إعدادات GTM ثم نشرها لاحقًا، ومسؤول DNS والاستضافة والاسترجاع، وبريد كل شخص لمنحه الدعوات.

GA4 Measurement ID وGTM Container ID معرّفات عامة وليسا كلمة مرور؛ نضعهما لاحقًا في إعدادات البيئة. Property ID المستخدم لتقارير لوحة CMS مختلف عن Measurement ID المستخدم لجمع الزيارات. إذا طُلبت تقارير GA4 داخل CMS لاحقًا، نحدد خدمة قراءة منفصلة وصلاحيتها ومخزن credential JSON الآمن؛ ليست مطلوبة لتتبع صفحات الموقع الآن.

لم تُرسل هذه القائمة إلى مارون، ولم تُنشأ حسابات أو تُغيّر صلاحيات أو DNS أو إعدادات إنتاج.
